# WebGL 手机技能冷却与普攻剑气就绪提示——设计

日期：2026-11-06

## 目标

为 `DemoDay` 的 WebGL 手机 HUD 增加完整技能按钮交互与冷却反馈：Q、R、火球、蓄力炎爆、陨石均可通过触摸操作；技能冷却使用径向遮罩和整数倒计时；普攻长按达到真实剑气可释放状态时，普攻按钮变为暖金色并显示金色外框。

## 布局

普攻按钮保持扇形圆心。按钮从左下向上方逆时针展开：

- 内层弧：防御、跳跃、突刺 Q、旋转 R。
- 外层弧：火球 1、蓄力炎爆 2、陨石 3。
- 切换目标按钮保持独立，不进入技能扇形。
- 普攻约 120–128 px，内层约 78–84 px，外层约 70–76 px。
- 内层半径约 115–125 px，外层半径约 185–200 px，按钮最小间距 10 px。
- 所有按钮必须完整位于 WebGL 安全区域内，且触摸射线首位命中自身。

## 输入语义

触摸输入必须沿用现有链路：

`MobileSkillButton → MobileActionButtons → MobileInputBinder → InputManager → Sys3CEntry → SkillCoordinator`

UI 不直接调用 `SkillCoordinator`，以保证触摸、键盘和联网施法走同一套规则。

- Q：按下产生一次 Q 输入。
- R：按下产生一次 R 输入；旋转期间再次按下沿用现有取消语义。
- 火球 1：按下开始蓄力，保持期间持续 held，松开释放。
- 蓄力炎爆 2：按下开始蓄力，保持期间持续 held，松开释放。
- 陨石 3：按下产生一次陨石输入。
- WebGL 页面失焦、按钮停用、触控模式关闭或本地角色销毁重建时，必须清除全部触摸 held/pressed 状态。

## 冷却与蓄力表现

每个技能按钮包含技能图标、径向冷却遮罩、倒计时文本、蓄力外环和快捷键角标。

- 冷却遮罩使用 `Image.Type.Filled + Radial360`，`fillAmount = Remaining / Total`，从满圆顺时针清空。
- 倒计时使用 `CeilToInt(Remaining)`；冷却结束时遮罩与文本同时隐藏。
- 冷却真值来自 `SkillCoordinator.GetCooldownInfo(skillId)`，UI 不维护独立计时器。
- 火球与蓄力炎爆在实际释放时开始冷却，与现有本地/服务端语义一致。
- 火球与蓄力炎爆处于 Charging 时，亮色外环显示 `CurrentSkill.GetChargeProgress()`；释放后外环隐藏并切换为冷却遮罩。
- 冷却时按钮仍可接收输入，由技能系统决定拒绝或缓冲。

## 普攻剑气就绪提示

剑气就绪不按固定按住秒数估算。唯一真值是现有战斗流程中的 `_canFireHeavy`：按下先释放轻击，继续按住，轻击完整结束后才进入可释放剑气状态。

- `Sys3CEntry` 暴露只读 `CanFireHeavy`，不复制判断逻辑。
- 未就绪：普攻按钮保持默认颜色和灰色边框。
- 就绪：图标染为暖金色，启用 `button-gold-round.png` 金色外框。
- 松手、被打断、死亡、进入防御、触控关闭或失焦时立即恢复默认状态。
- 金边保持稳定，不闪烁，避免暗示额外的释放窗口。

## 测试与验收

- EditMode：触摸 Q/R/3 每次按下只产生一个输入；1/2 正确产生 pressed、held、released；清理路径不残留状态。
- EditMode：冷却遮罩、倒计时向上取整、蓄力外环、剑气金边的纯显示状态可独立验证。
- PlayMode：8 个动作/技能按钮均在屏内、射线可点击；双层扇形顺序与间距符合设计。
- PlayMode：按住普攻直至轻击完成后出现金边，松手后消失并触发重击路径。
- PlayMode：按住火球/炎爆后松手，状态从蓄力外环切到冷却遮罩。
- WebGL 手工验收：真机浏览器点击、长按、滑出、切后台再回来均不发生卡住持续施法。
