# 轻击/重击系统设计

## 概述

将当前单一普攻改为单键双态攻击系统：点击触发轻击（横劈），长按触发重击（竖劈蓄力）。

## 按键设计

```
攻击键 ── 按下 ──┬─ 0.2s 内松开 → 轻击（横劈·扇形AOE）
                 │
                 └─ 超过 0.2s → 进入重击蓄力 → 松手释放（竖劈·单体）
```

## 轻击（横劈）

| 参数 | 值 |
|------|-----|
| 技能资产 | BA_Combo1（ComboSkillData） |
| 检测范围 | 2 单位 |
| 扇形角度 | -15° ~ 45°（偏右，覆盖前方） |
| 判定时机 | 技能开始后 0.3s |
| 频率限制 | 动画驱动 + 可取消窗口 + 多余输入丢弃 |

## 重击（竖劈）

| 参数 | 值 |
|------|-----|
| 技能资产 | BA_Heavy（ChargedSkillData，新建） |
| 检测范围 | 2.5 单位 |
| 扇形角度 | -10° ~ 10°（窄扇形，直线方向） |
| 最小蓄力 | 0.3s |
| 最大蓄力 | 0.8s（到时间自动释放） |
| 暴击率加成 | +10% |
| 伤害倍率 | 基础 2 倍，蓄力进度额外加成 |
| 移动 | 蓄力期间站桩 |

## 伤害公式

```
横劈伤害 = BaseDamage + AttackRatio × AttackPower
竖劈伤害 = BaseDamage × 2.0 × (1 + 蓄力进度 × 0.5)
暴击 = 暴击率 × (1 + 1.5 + 爆伤加成)
```

## 命中检测（共用）

使用 OverlapSphere + 扇形角度过滤替代原有 Raycast：
- 以角色中心为球心
- Range 为半径
- AngleStart ~ AngleEnd 过滤有效目标
- 支持多目标命中（横劈扫多个，竖劈通常 1 个）

## 中断规则

| 当前 | 能被轻击中断？ | 能被重击中断？ | 能被伤害中断？ |
|------|:---:|:---:|:---:|
| 轻击执行中 | 否 | 否 | 否（Combo 不可被同源中断） |
| 轻击可取消窗口 | 是 | 是 | 否 |
| 重击蓄力中 | 否 | — | 是 |
| 重击执行中 | 否 | — | 否 |
