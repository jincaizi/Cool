UIPanel Integration
TargetPanel : UIPanel
├── Layer = Base (1000, 常驻HUD区域)
├── Mode = CanvasGroup (快速切换)
│
├── Image _portrait
├── TMP_Text _name / _level
├── Slider _hpBar
├── TMP_Text _hpText
│
└── Bind(ITargetable target)
    target.OnHPChanged += RefreshHP
    target.OnDeath += Clear

Select / Deselect Flow

// Player clicks/tabs to target a monster
SelectTarget(monster) →
  1. UIManager.ShowAlwaysAsync("TargetPanel")
  2. TargetPanel.Bind(monster)
    → set portrait, name, level
    → subscribe monster.OnHPChanged

// Target dies or player deselects
ClearTarget() →
  1. TargetPanel.Clear()
    → unsubscribe events
  2. UIManager.HideAlwaysAsync("TargetPanel")
    → play hide animation → CanvasGroup off

ITargetable Interface

public interface ITargetable
{
  string DisplayName { get; }
  int Level { get; }
  Sprite Portrait { get; }
  float HPPercent { get; }
  int CurrentHP { get; }
  int MaxHP { get; }
  Vector3 WorldPosition { get; }
  event Action<float, int, int> OnHPChanged;
  event Action OnDeath;
}

// MonsterEntity and Player both implement ITargetable
// TargetPanel binds to ITargetable, not concrete types
