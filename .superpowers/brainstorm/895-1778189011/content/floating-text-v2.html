Pool Design
FloatingTextPool
├── Stack<TextMeshProUGUI> _free (idle pool)
├── HashSet<TextMeshProUGUI> _active (in use)
├── int _growSize = 10
│
├── PreWarm(10) // init 10
├── Spawn(pos, text, cfg)
│ ├── _free.Count == 0 → Grow(10) instantiates 10 new
│ ├── Pop from _free, add to _active
│ ├── Set text/color/size/pos
│ ├── Play DOTween → on complete → Enqueue
│ └── return
└── Enqueue(tmp) // back to _free
Grow Strategy
Start: 0 items
PreWarm(10) → 10 in _free pool

First 10 spawns → instant, no allocation
11th spawn → _free empty
→ Grow(10): Instantiate 10 new TMP
→ use 1, 9 in _free

Max capacity: unbounded (but practically ~30-40 for 100-monster scenarios)

Spawn Lifecycle

1. Pop TMP from _free stack (Grow if empty)
2. Set text, color, fontSize from FloatingTextConfig
3. Position: Camera.main.WorldToScreenPoint(worldPos + offsetY)
4. Play DOTween Sequence per config
5. OnComplete → reset alpha/scale → push back to _free stack
