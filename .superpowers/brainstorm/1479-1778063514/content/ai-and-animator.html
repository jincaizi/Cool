怪物 AI 行为 & Animator 设计

基于现有 MonsterAI FSM，扩展差异化行为

Slime — 高速攻击型

AI 状态行为动画Animator 参数
Idle原地等待 2sIdleNormalAIState=0
Patrol巡逻点间走动Walk + 方向混合AIState=1
Chase追击玩家RunAIState=2
AttackAttack01 (快) / Attack02 (慢重击)Attack01 / Attack02AIState=3 + Attack trigger
Hit受击硬直GetHitHit trigger
Death死亡→销毁DieDeath trigger
Taunt (新)攻击落空后嘲讽TauntTaunt trigger

Slime 特有逻辑：攻击时随机选 Attack01(70%) / Attack02(30%)。攻击后如果玩家不在攻击范围内→触发 Taunt。SenseSomething 动画在 Idle 状态下，检测到玩家但距离不够时播放。

TurtleShell — 防御反击型

AI 状态行为动画Animator 参数
Idle/Patrol/Chase同 Slime，速度慢Idle/Walk/RunAIState=0/1/2
AttackAttack01 (旋转) / Attack02 (头槌)Attack01 / Attack02AIState=3 + Attack trigger
Defend (新)举壳防御，正面减伤80%Defend (循环)AIState=7 + IsDefending=true
Hit受击，防御中→DefendHitGetHit / DefendHitHit trigger
Death死亡→销毁DieDeath trigger

TurtleShell 特有逻辑：HP < 50% 或进入 Chase 后 3s → 进入 Defend 状态。Defend 持续 2s，期间正面 180° 减伤 80%。被击中 N 次后→反击（Attack02 + 50% 伤害加成）。Defend 后进入攻击。

Animator Controller 结构

Slime Animator (Base Layer)
  Any State ──Death trigger──▶ Die
  Any State ──Hit trigger────▶ GetHit
  Any State ──Taunt trigger──▶ Taunt

  IdleNormal ◀──▶ Walk (BlendTree: Fwd/Back/Left/Right)
       │              ▲
       │ (AIState↓)   │ (AIState↑)
       ▼              │
  IdleBattle ───────▶ Run
       │
       │ Attack trigger
       ▼
  Attack01 ◀──▶ Attack02
       │              │
       └──── Exit ────┘ → 返回 IdleBattle

参数：AIState(int), Attack(trigger), Hit(trigger), Death(trigger), Taunt(trigger), Speed(float, 用于 BlendTree)

TurtleShell Animator (Base Layer)
  Any State ──Death trigger──▶ Die
  Any State ──Hit trigger────▶ GetHit
  Any State ──IsDefending────▶ Defend (loop)
       │
  Defend ──Hit trigger────▶ DefendHit → Defend

  IdleNormal ◀──▶ Walk (BlendTree)
       │              ▲
       ▼              │
  IdleBattle ───────▶ Run
       │
       │ Attack trigger
       ▼
  Attack01 ◀──▶ Attack02

参数：AIState(int), Attack(trigger), Hit(trigger), Death(trigger), IsDefending(bool), Speed(float)
