技能 × AttackShape 复用设计

AttackShape 只管"打中谁"，技能负责"何时打、怎么动、打几次"

一个技能 = Shape + 执行模式 + 移动行为

  ┌──────────────────────────────────────────────────────┐
  │                    SkillConfig                       │
  ├──────────────────────────────────────────────────────┤
  │  AttackShape        ← 复用！打到谁                    │
  │  AttackEffects[]    ← 复用！打中后的效果               │
  │  ExecutePattern     ← 技能专属：执行模式               │
  │  MoveBehaviour      ← 技能专属：释放时怎么动           │
  │  TargetingMode      ← 技能专属：怎么选目标             │
  └──────────────────────────────────────────────────────┘
维度选项示例
ExecutePattern
执行模式		 Instant — 单次判定
Pulse — 持续期间每N秒判定一次
Channel — 蓄力后释放（蓄力期间可打断）
Combo — 多段依次执行 		普攻=Instant
R技能=Pulse (每0.5s一次)
蓄力斩=Channel
三连击=Combo
MoveBehaviour
移动行为		 Root — 原地不动
Free — 可自由移动
Dash — 强制位移（方向距离） 		普攻=Root
R技能=Free
Q技能=Dash
TargetingMode
目标选择		 Forward — 角色前方
Self — 自身为中心
Target — 锁定目标
Ground — 地面位置 		普攻=Forward
R技能=Self
Q技能=Forward
火球=Target

Shape 复用全景

AttackShape普攻技能怪物攻击
ConeShape 剑横扫、斧下劈 剑气（前方扇形远程） Slime咬、龙爪挥击
CircleShape — Skill R 旋转斩
旋风斩、冰环		 TurtleShell 旋转
Boss 践踏
RectShape 枪突刺 Skill Q 突刺
冲锋、穿透箭		 Boss 冲撞、龙车
RayShape 弓普攻（未来） 狙击、连锁闪电 Boss 激光、喷吐

✅ 同一个 CircleShape 类 → TurtleShell 旋转攻击 + 角色 Skill R + 未来 Boss 践踏
✅ 同一个 RectShape 类 → 角色 Skill Q 突刺 + 未来 Boss 冲撞
✅ 新增技能只需在 SkillConfig 里选 Shape + 配参数，不写新代码

SkillConfig 扩展示例

// 现有 SkillConfig 新增字段
public class SkillConfig : ScriptableObject
{
    public string SkillId;
    public float Cooldown;
    public float MaxDuration;
    public AnimationClip Anim;

    // === 新增：攻击相关（复用 AttackShape 体系）===
    public AttackShapeConfig AttackShape;     // 选 Cone / Circle / Rect / Ray
    public AttackEffectConfig[] Effects;      // 命中效果
    public ExecutePattern Pattern;            // Instant / Pulse / Channel / Combo
    public MoveBehaviour MoveLock;            // Root / Free / Dash
    public TargetingMode Targeting;           // Forward / Self / Target / Ground

    // Dash 参数（MoveLock==Dash 时生效）
    public float DashDistance;
    public float DashDuration;

    // Pulse 参数（Pattern==Pulse 时生效）
    public float PulseInterval;              // 多少秒判定一次
    public float PulseDuration;              // 持续多久
}

总结：Shape 对重构工作量的影响

场景不用 Shape用 Shape 体系
新增近战武器（斧）配 ConeShape 参数即可同上，零额外工作
新增远程武器（弓）写整套射线检测 + 弹道系统实现 RayShape + 配参数，~40行
新增技能（地裂斩）手写 RectShape 等价逻辑SkillConfig 配 RectShape，0行
新增怪物（Boss）每种攻击形状手写检测MonsterConfig 选 Shape，0行
Skill Q 命中判定SkillDashComponent 自带碰撞保持现有 Dash 移动，命中改用 RectShape
Skill R 范围判定手写 OverlapSphere + 间隔循环CircleShape + Pulse 模式，0行手写
