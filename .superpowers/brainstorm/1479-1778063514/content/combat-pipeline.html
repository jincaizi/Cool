完整战斗数据流

攻击流（左→右）和受击流（右→左）

  ┌───────────────────【角色攻击怪物】────────────────────┐
  │                                                        │
  │  玩家按键(J) → FSMManager.RequestNormalAttack()        │
  │       │                                                │
  │       ▼ AttackFSM → AttackStateBehaviour               │
  │       │ OnStateEnter 时触发 OnAttackFrame 回调          │
  │       ▼                                                │
  │  CharacterAttackHandler.AttackInFront()               │
  │       │ ① SphereCast 前方检测 IDamageable               │
  │       │ ② 过滤距离 & 角度                               │
  │       │ ③ 生成 DamageData (从角色属性计算)              │
  │       ▼                                                │
  │  MonsterEntity.TakeDamage(data, hitDirection)          │
  │       │                                                │
  │       ▼ MonsterStats.TakeDamage → MonsterAI.NotifyHit  │
  │                                                        │
  └────────────────────────────────────────────────────────┘

  ┌───────────────────【怪物攻击角色】────────────────────┐
  │                                                        │
  │  MonsterAI.TransitionTo(Attack)                         │
  │       │                                                │
  │       ▼ OnAttackFrame → MonsterAttackHitbox.Activate() │
  │       │ 激活 Collider (Trigger)                         │
  │       ▼                                                │
  │  碰撞检测: 怪物 AttackHitbox.OnTriggerEnter(Collider)   │
  │       │                                                │
  │       ▼ 对方是 CharacterHitZone?                        │
  │  CharacterHitZone.OnTriggerStay()                     │
  │       │ 读取 hitbox.CurrentData (包含 DamageData)       │
  │       ▼                                                │
  │  角色 Stats 扣血 + Hit FSM 受击                         │
  │                                                        │
  └────────────────────────────────────────────────────────┘

新增组件清单

CharacterAttackHandler

挂载在角色身上

  • AttackRange — 攻击距离 (2f)
  • AttackAngle — 攻击扇形角度 (120°)
  • AttackDamage — 基础伤害数据
  • AttackInFront() — 从 Sys3CEntry/FSMManager 调用
  • 内部用 Physics.OverlapSphere + 角度过滤找最近目标
  • 调用 IDamageable.TakeDamage()
CharacterHitZone

挂载在角色身上（子物体 + Collider）

  • 同 MonsterHitZone 逻辑
  • OnTriggerStay 检测 IAttackHitbox
  • 去重已处理的 hitSource
  • 转发伤害到角色 Stats 和 HitFSM
  • 需要角色侧 IDamageable 实现

接入 Sys3CEntry 的方式

// Sys3CEntry 中新增
private CharacterAttackHandler _attackHandler;
private CharacterHitZone _hitZone;

void Start()
{
    // ...现有初始化...
    _attackHandler = GetComponent<CharacterAttackHandler>();
    _hitZone = GetComponentInChildren<CharacterHitZone>();

    // 注册攻击帧回调
    _fsmManager.OnAttackFrame += () =>
    {
        _attackHandler?.AttackInFront();
    };
}

需要处理的关键细节

  • HitZone 去重 — 同 MonsterHitZone，用 HashSet<IAttackHitbox> 防止同一攻击多次触发
  • 怪物攻击激活时机 — OnAttackFrame 激活 Hitbox，动画 OnStateExit 时 Deactivate
  • 角色 Stats 适配 — CharacterStatsAdapter 已有 Health/Attack 属性，CharacterAttackHandler 读取它计算伤害
  • Layer 过滤 — CharacterAttackHandler 只检测 Monster 层，CharacterHitZone 只响应怪物 AttackHitbox 层
