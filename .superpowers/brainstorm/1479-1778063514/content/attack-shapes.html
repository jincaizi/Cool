攻击范围设计 — 面向扩展重构

核心思路：把"攻击形状"从角色/怪物身上剥离，变成可插拔的独立抽象

当前设计的问题

组件当前攻击方式无法支持
CharacterAttackHandler 前方扇形检测（硬编码） 弓的射线/弹道、法杖的圆形AOE、枪的直线穿透
MonsterAttackHitbox 触发碰撞器（Collider Trigger） 怪物远程喷吐、地面预警圈、冲锋路径检测
AttackResolver OverlapSphere + 角度过滤 只有扇形，没有圆形/矩形/射线/弹道

核心抽象：AttackShape

角色攻击和怪物攻击都用同一套 AttackShape。区别只在于触发时机和参数来源。

IAttackShape 接口 + 内置实现
// 攻击形状接口 — 只管"在空间中找出被打到的目标"
public interface IAttackShape
{
    /// 执行攻击检测，返回所有命中的 IDamageable
    IReadOnlyList<IDamageable> Resolve(
        Vector3 origin, Vector3 forward, LayerMask targetMask);
}

// 四种内置实现覆盖所有场景
public class ConeShape : IAttackShape        // 扇形 — 剑横扫、斧劈砍
{
    public float Range;
    public float Angle;     // 扇形角度
}

public class CircleShape : IAttackShape      // 圆形 — 旋风斩、怪物践踏
{
    public float Radius;
}

public class RectShape : IAttackShape        // 矩形 — 冲锋、长枪突刺
{
    public float Length;
    public float Width;
}

public class RayShape : IAttackShape         // 射线/弹道 — 弓、枪、怪物喷吐
{
    public float MaxRange;
    public float Width;     // 0=精准射线, >0=弹道宽度
    public bool StopAtFirstHit;
}

统一后的攻击流程

  ┌─────────────────────────────────────────────────────────┐
  │           动画帧触发 (角色 和 怪物 走同一条管道)          │
  │                                                         │
  │  武器配置 / 怪物Config                                   │
  │       │                                                 │
  │       ▼ 读取 AttackShape + AttackEffects                 │
  │  shape.Resolve(origin, forward, targetMask)             │
  │       │                                                 │
  │       ▼ 返回 IDamageable[]                               │
  │  foreach target:                                        │
  │      foreach effect in AttackEffects:                   │
  │          target.ApplyDamage(effect.Damage)              │
  │          target.ApplyKnockback(effect.KnockbackForce)   │
  │          target.ApplyStatus(effect.Status)              │
  │                                                         │
  └─────────────────────────────────────────────────────────┘

  关键点：
  · 角色用 IWeapon.Shape，怪物用 MonsterConfig.AttackShape
  · 同一套 IAttackShape 实现，不存在"角色版"和"怪物版"
  · 新增攻击类型 = 新增一个 IAttackShape 实现（或调现有参数）

和之前设计的关系

之前：AttackResolver 硬编码扇形
// 只能做扇形
AttackResolver.FindNearestTarget(
    origin, forward, range, angle, mask);

// 要做圆形AOE？
// → 改 AttackResolver 加方法
// 要射线？
// → 再加方法，类越来越胖
现在：AttackShape 多态
// 统一入口，行为由 shape 决定
var hits = weaponConfig.AttackShape
    .Resolve(origin, forward, targetMask);

// 所有形状共用一个接口
// 加新形状 = 新建一个类
// 无需改现有代码

Config 结构更新
