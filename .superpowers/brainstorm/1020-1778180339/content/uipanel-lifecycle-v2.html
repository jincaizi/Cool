UIPanel Base Class & Lifecycle (Revised)

移除 OnPreHide，精简为 5 个钩子

Lifecycle (Show → Hide)
OnPreShow() — 构建/刷新数据，绑定 Model 引用
PlayShowAnimation() — 返回 DOTween Sequence，入场动画
OnShow() — 动画完成后，注册事件/启动协程
... panel is visible ...
PlayHideAnimation() — 返回 DOTween Sequence，出场动画
OnHide() — 注销事件/清理引用，之后 UIManager 执行显隐
Show Flow
1. Set visibility ON (per panel.Mode)
2. OnPreShow() → refresh data
3. PlayShowAnimation() → DOTween sequence
4. await sequence
5. OnShow() → register events
6. IsVisible = true
Hide Flow
// Caller cleans up before calling UIManager.Hide() if needed
1. OnHide() → unregister events, clear refs
2. PlayHideAnimation() → DOTween sequence
3. await sequence
4. Set visibility OFF (per panel.Mode)
5. IsVisible = false

UIPanel Abstract Members

public abstract class UIPanel : MonoBehaviour
{
  public abstract LayerType Layer { get; }      // Base/Main/Popup/Top/Guide
  public abstract VisibilityMode Mode { get; }  // ToggleActive/CanvasSwitch/CanvasGroup
  public abstract string PanelId { get; }        // Unique ID, e.g. "BagPanel"

  // Virtual lifecycle hooks (override as needed)
  protected virtual void OnPreShow() { }
  protected virtual Sequence PlayShowAnimation() { return null; }
  protected virtual void OnShow() { }
  protected virtual Sequence PlayHideAnimation() { return null; }
  protected virtual void OnHide() { }
}
