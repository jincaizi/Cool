Show/Hide Performance Strategy

混合策略 — UIPanel 声明 VisibilityMode，UIManager 自动处理

Three Visibility Modes (UIPanel.VisibilityMode)
Mode Mechanism Performance Use Case
ToggleActive SetActive(true/false) ★☆☆☆ Show
★★★★ Hide (完全释放)		 低频面板：背包、技能、设置
CanvasSwitch Canvas.enabled ★★★★ Show
★★★☆ Hide (保留树)		 中频面板：HUD 子模块、弹窗
CanvasGroup alpha=0 + blocksRaycasts=false ★★★★★ Show
★★☆☆ Hide (仍在渲染)		 高频切换：Tips、Toast、HUD 元素

UIPanel Declaration

Each Panel declares its preferred mode
public class BagPanel : UIPanel
{
  // Low-frequency = SetActive for full release
  public override VisibilityMode Mode => VisibilityMode.ToggleActive;
}

public class HUDHealthBar : UIPanel
{
  // High-frequency = CanvasGroup for instant toggle
  public override VisibilityMode Mode => VisibilityMode.CanvasGroup;
}

public class ConfirmDialog : UIPanel
{
  // Medium-frequency = Canvas.enabled
  public override VisibilityMode Mode => VisibilityMode.CanvasSwitch;
}

UIManager Show/Hide Logic

internal void Show(UIPanel panel)
{
  switch (panel.Mode)
  {
    case ToggleActive: panel.gameObject.SetActive(true); break;
    case CanvasSwitch: panel.Canvas.enabled = true; break;
    case CanvasGroup: panel.CanvasGroup.alpha = 1; panel.CanvasGroup.blocksRaycasts = true; break;
  }
  panel.OnShow();
}

// For ToggleActive mode, UIManager calls OnHide() → play exit anim → SetActive(false)
// For CanvasSwitch/CanvasGroup, UIManager just calls OnHide() + plays exit anim + disables Canvas/CanvasGroup
