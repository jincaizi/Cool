UIPanel Lifecycle (Final)

Show 和 Hide 对称：Prepare → Animate → Callback → Visibility

Show Flow
1. Visibility ON (per panel.Mode)
2. OnPreShow()
准备数据，绑定 Model，刷新 UI
3. PlayShowAnimation()
入场动画 (DOTween Sequence)
4. OnShow()
注册事件/监听，启动逻辑
5. IsVisible = true
Hide Flow
1. PlayHideAnimation()
出场动画 (DOTween Sequence)
2. OnHide()
注销事件，清理引用
3. Visibility OFF (per panel.Mode)
4. IsVisible = false
Symmetry
Show: Prepare data → Animate IN → Events ON → Visible
Hide: Animate OUT → Events OFF → Invisible

// During show animation, data is populated but events not yet registered
// During hide animation, events are still active so the panel is functional until visually gone
// After hide animation, events are cleaned up, then visibility is turned off
UIPanel Code
public abstract class UIPanel : MonoBehaviour
{
  public abstract LayerType Layer { get; }
  public abstract VisibilityMode Mode { get; }
  public abstract string PanelId { get; }

  protected virtual void OnPreShow() { }        // prepare data
  protected virtual Sequence PlayShowAnimation() { return null; }
  protected virtual void OnShow() { }           // register events
  protected virtual Sequence PlayHideAnimation() { return null; }
  protected virtual void OnHide() { }           // unregister events
}
