5-Layer Canvas Architecture

每个 Layer 对应一个独立 Canvas，由 UIManager 统一管理

Canvas Layer Stack (从下到上)
Layer 5: Guide — 新手引导蒙版/高亮 (sort=5000)
Layer 4: Top — Loading遮罩 / Toast消息 (sort=4000)
Layer 3: Popup — 确认框 / Tips / 弹窗 (sort=3000)
Layer 2: Main — 背包 / 技能 / 角色信息 / 设置 (sort=2000)
Layer 1: Base — HUD / 摇杆 / 常驻信息栏 (sort=1000)
Layer Properties (UIConst.LayerType)
Layer Canvas Sort Type
Guide5000Overlay
Top4000Overlay
Popup3000Stack
Main2000Stack
Base1000Always

Layer Behavior

Overlay (Guide / Top)

  • 不受面板栈控制
  • UIManager 按 ID 独立 Show/Hide
  • 多个 Overlay 可同时显示

Stack (Main / Popup)

  • 走栈式管理，Push/Pop
  • 打开新面板会遮挡下层
  • 返回操作自动 Pop 栈顶
UIManager Stack Logic
Push("BagPanel") → Stack: [BagPanel]
Push("ItemDetail") → Stack: [BagPanel, ItemDetail]
Pop() → Stack: [BagPanel] (ItemDetail closes with exit anim)

Overlay panels (Toast, Loading, Guide) are NOT pushed to stack
