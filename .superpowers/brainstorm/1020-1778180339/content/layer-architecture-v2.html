5-Layer Canvas Architecture (Updated)

Top 层新增 Network 类型面板，用于断线重连等全局系统提示

Canvas Layer Stack (从下到上)
Layer 5: Guide — 新手引导蒙版/高亮 (sort=5000, Overlay)
Layer 4: Top — Loading遮罩 / 重连提示 / Toast消息 (sort=4000, Overlay)
Layer 3: Popup — 确认框 / Tips / 弹窗 (sort=3000, Stack)
Layer 2: Main — 背包 / 技能 / 角色信息 / 设置 (sort=2000, Stack)
Layer 1: Base — HUD / 摇杆 / 常驻信息栏 (sort=1000, Always)

Top 层职责（Updated）

Loading 遮罩

场景切换、资源加载中的全屏遮罩

Network Reconnect

断线重连按钮/状态提示，全局可见

Toast 消息

系统通知、错误提示、浮动消息

System Overlay

其他全局系统级提示

Overlay vs Stack Behavior
Overlay (Guide / Top):
Open("ReconnectBtn") → 直接显示，栈不变
Open("Toast_X") → 直接显示，栈不变
Close("ReconnectBtn") → 直接隐藏

Stack (Main / Popup):
Push("BagPanel") → 入栈
Push("ConfirmDialog") → 入栈，BagPanel 被遮挡
Pop() → 出栈，恢复 BagPanel

Always (Base):
HUD 始终显示，不受栈和 Overlay 影响
