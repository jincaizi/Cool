UIPanel Base Class & Lifecycle

所有 UI 面板的基类，定义生命周期、显隐模式、动画钩子

UIPanel Core
public abstract class UIPanel : MonoBehaviour
{
  // Layer this panel belongs to
  public abstract LayerType Layer { get; }

  // Show/hide performance mode
  public abstract VisibilityMode Mode { get; }

  // Unique panel ID
  public abstract string PanelId { get; }

  // Lazy-loaded component refs
  public Canvas Canvas { get; private set; }
  public CanvasGroup CanvasGroup { get; private set; }
  public UIAnimation Animation { get; private set; }

  // State
  public bool IsVisible { get; private set; }
}
Lifecycle (Show → Hide)
OnPreShow()
刷新数据、绑定 Model
PlayShowAnimation()
入场动画（DOTween）
OnShow()
动画完成后回调
... is visible ...
OnPreHide()
准备隐藏
PlayHideAnimation()
出场动画（DOTween）
OnHide()
动画完成后，UIManager 执行 SetActive/canvas.enabled/alpha
Show Flow (with Animation)
// UIManager.Show(panel):
1. Set visibility ON (SetActive / Canvas.enabled / CanvasGroup)
2. OnPreShow() → panel refreshes data
3. PlayShowAnimation() → DOTween sequence
4. await animation
5. OnShow() → callback after animation
6. IsVisible = true

// UIManager.Hide(panel):
1. OnPreHide()
2. PlayHideAnimation() → DOTween sequence
3. await animation
4. OnHide()
5. Apply visibility OFF per panel.Mode
6. IsVisible = false
