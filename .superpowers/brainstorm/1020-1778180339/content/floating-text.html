FloatingText — Object Pool & Animation System

预建50个TMP对象 / Screen Space Canvas投影 / DOTween动画 / 零GC

Pool Design
FloatingTextPool
├── Queue<TextMeshProUGUI> _pool (50 items)
├── Transform _canvasTransform (Screen Space)
├── Canvas _floatingCanvas (独立Canvas, sort=4500)
│
├── Spawn(worldPos, text, config)
│ └── Dequeue → Set text/color/pos → Play anim → Enqueue
└── PreWarm(count) // init 50
FloatingTextConfig (Presets)
Preset Color Size Animation
Damage #FF4444 36 ↑50px + fade out, 1s
CritDamage #FF8800 42 ↑70px + punch scale, 1.2s
Heal #44FF44 32 ↑40px + fade out, 1s
SkillName #FFD700 28 scale 0.8→1.2→1 + fade, 1.5s

Lifecycle (per spawn)

1. Dequeue from pool (if empty, drop oldest active) 2. Set text + color + fontSize from config 3. Position: Camera.WorldToScreenPoint(worldPos + offsetY) 4. Play DOTween Sequence (move up + fade out + scale) 5. await sequence completion 6. Enqueue back to pool, reset alpha/scale
Damage Event Hook
// EventBus listener in FloatingTextPool or a bridge component
EventBus.Subscribe<DamageEvent>(e => {
  var cfg = e.IsCritical ? CritDamage : Damage;
  pool.Spawn(e.TargetPosition, $"-{e.Damage}", cfg);
});
