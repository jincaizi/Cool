UIPanel Lifecycle (Final)

Hide 时先移除功能再播动画——关闭瞬间即停止交互，动画仅视觉过渡

Show Flow
1. Visibility ON (per panel.Mode)
2. OnPreShow()
准备数据、绑定 Model、刷新 UI 内容
3. PlayShowAnimation()
入场动画
4. OnShow()
注册事件、启动逻辑
5. IsVisible = true
Hide Flow
1. OnHide()
立即注销事件/监听，停止交互 — 面板已不可用
2. PlayHideAnimation()
纯视觉退场动画（fade/scale），面板功能已停
3. Visibility OFF (per panel.Mode)
4. IsVisible = false
Code
protected virtual void OnPreShow() { }        // prepare data, bind model
protected virtual Sequence PlayShowAnimation() { return null; }
protected virtual void OnShow() { }           // register events, start logic
protected virtual void OnHide() { }           // unregister events FIRST, stop interaction
protected virtual Sequence PlayHideAnimation() { return null; }  // then play exit animation
